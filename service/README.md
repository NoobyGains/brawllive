# Matchmaking service (sub-project 2)

Node.js + TypeScript + PostgreSQL. Not started; spec sections 6.2, 7, 8, 10 and 11 define it. A plan is written once sub-project 1 passes its milestone.

Will contain: the agent API (`/v1/devices`, `/v1/agent/commands`, `/v1/agent/events`), the queues and matcher, the match state machine with per-stage timeouts, ratings (sub-project 4), the admin surface, and the contract tests driven by a simulated agent.
